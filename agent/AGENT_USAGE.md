# Coding Agent Usage

## Empfohlener Startprompt

Lade zuerst:

```text
agent/SYSTEM_PROMPT.md
```

und gib dem Agent zusätzlich Zugriff auf:

```text
docs/chapters/
docs/cheatsheets/
docs/quizzes/
docs/coding-katas/
progress/
```

## Session Start

```text
Start a new Java handcoding training session.
Read the current knowledge tracker and mistake log first.
Continue with the weakest relevant topic.
```

## Kapitel lernen

```text
NEXT CHAPTER
```

## Quiz

```text
QUIZ
```

## Coding

```text
CODING
```

## Wiederholen

```text
REPEAT
```

## Thema gezielt erklären

```text
EXPLAIN Collectors.toMap
```

## Prüfung

```text
START FINAL EXAM
```

## Regel

Der Agent soll Lösungen nicht vor deinem ersten Versuch zeigen.
