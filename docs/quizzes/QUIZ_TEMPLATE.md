# Quiz Template

## Level 1 – Recall

5–10 kurze Fragen.

## Level 2 – Understanding

5 Verständnisfragen.

## Level 3 – Code Reading

3 Code-Snippets.

Fragen:

- Was ist der Rückgabetyp?
- Was passiert?
- Wo steckt ein Fehler?
- Wie würdest du den Code verbessern?

## Level 4 – Coding

3 kleine Coding-Aufgaben.

## Level 5 – Refactoring

1 absichtlich schlechter Codeblock.

## Bewertung

```text
Recall          20
Understanding   20
Code Reading    20
Coding          30
Clean Code      10
-------------------
Gesamt         100
```

## Interpretation

```text
90–100  sehr sicher
80–89   sicher
70–79   brauchbar
60–69   wiederholen
<60     Kapitel erneut lernen
```
