# 10-Tage-Lernplan

## Tag 1 – Core Java

Themen:

- Klassen
- Konstruktoren
- `final`
- Primitive vs Wrapper
- Strings
- `var`
- Switch Expressions
- Enums
- BigDecimal

Praxis:

- `User`
- `Product`
- `Order`

selbst modellieren.

---

## Tag 2 – Collections

Trainieren:

- `List`
- `Set`
- `Map`
- `ArrayList`
- `HashSet`
- `HashMap`

Aufgaben:

- Duplikate entfernen
- Lookup Map bauen
- gruppieren
- zählen

---

## Tag 3 – Streams Basics

Trainieren:

- `filter`
- `map`
- `sorted`
- `distinct`
- `findFirst`
- `anyMatch`
- `allMatch`
